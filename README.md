# AI Customer Support Assistant: Requirements, Pilot Plan and ROI

A business analysis case study: should an online retailer use an AI assistant for customer
support chats, for which requests, and how would it know the assistant is working?

**Status:** In progress

## The problem

A growing online retailer's support team spends much of its time on repetitive,
policy-driven requests. Leadership wants to know whether an AI assistant could take some
of that work safely, and what it would save. The full context is in the
[project brief](docs/01_project_brief.md).

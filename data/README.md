# Data

This project uses the **Action-Based Conversations Dataset (ABCD)** from ASAPP Research. It contains:

- about 10,000 customer service chat conversations across 55 request types
- the Agent Guidelines, which are the company policy rules agents had to follow

The raw data is **not** stored in this repo. To download it:

```bash
git clone https://github.com/asappresearch/abcd.git
```

Then copy the files from the cloned repo's `data/` folder into this folder.
See the ABCD repository for the exact file names and its license.

**Citation:** Chen, D., Chen, H., Yang, Y., Lin, A., & Yu, Z. (2021).
*Action-Based Conversations Dataset: A Corpus for Building More In-Depth
Task-Oriented Dialogue Systems.* NAACL 2021.
